# Montfort Digital Challenge

A starter Node.js quiz application for a school exhibition.

## Included
- Three rounds, seven questions per round
- Pass mark: 5 correct answers out of 7 in each round
- Visitor and Student start modes
- QR code shown on the host screen
- Correct/incorrect sound effects generated by the browser
- Live leaderboard shared through Socket.IO
- Projector-friendly host page

## Requirements
- Node.js 18 or newer
- All phones and the host computer on the same Wi-Fi for local testing

## Run on Windows
1. Extract this ZIP file.
2. Install Node.js from https://nodejs.org/ if it is not installed.
3. Open the extracted `montfort_digital_challenge` folder.
4. Click the folder address bar in File Explorer, type `cmd`, and press Enter.
5. Run:

   ```bash
   npm install
   npm start
   ```

6. On the host computer, open `http://localhost:3000/host`.
7. The host page displays the QR code and live leaderboard.
8. Visitors scan the QR code using phones connected to the same Wi-Fi.

## Student participation
On a school computer, open `http://localhost:3000/` and choose **Student**.

## Important QR / network note
The QR code uses the host computer's local network address. Phones must be connected to the same Wi-Fi, and the Windows firewall may ask permission for Node.js; allow access on the private network. If the QR link does not open, check the IP address printed in the command window and ensure the host computer and phones are on the same network.

For visitors using mobile data or a different network, deploy the application to a public Node.js host with HTTPS. The QR code will then use that public URL.

## Important limitations of this starter
- Player records are held in server memory. Restarting the server clears the leaderboard.
- This is a prototype for a single exhibition session, not a permanent results database.
- The app uses an internet-hosted QR library and Google Fonts. Sound effects are generated in the browser and do not need audio files.
- Before the event, test on the actual school Wi-Fi and several phones.

## Customising questions
Edit the `rounds` array in `public/game.js`. Each question is:
`["Question text", ["Option A", "Option B", "Option C", "Option D"], correctOptionIndex]`
The correct option index starts at 0.
